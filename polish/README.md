# 潤稿台

一頁式的文字潤飾工具，有四種模式：

| 模式 | 做什麼 |
| --- | --- |
| 潤飾繁中 | 把中文潤飾成通順的臺灣繁體中文：修正錯字、「的／地／得」、歐化句、標點；夾雜的簡體字或大陸用語會改成臺灣用法。 |
| 轉簡體 | 繁體轉簡體，並把用語換成大陸說法（軟體 → 软件、影片 → 视频、網路 → 网络），引號改成 “”。 |
| 中英互換 | 依原文自動判斷方向：中文翻成自然的英文（可選美式或英式拼寫），英文翻成臺灣繁體中文。 |
| 原語潤飾 | 任何語言都用原本的語言潤飾，不翻譯。 |

每種模式都可以調整語氣（保持原文、正式、輕鬆、商務、學術）、修改幅度、速度，也可以加上補充指示。結果會附上修改說明；「潤飾繁中」與「原語潤飾」可以切換到「標示修改」，用紅筆標出刪除與新增的文字。

## 怎麼用

- **在 claude.ai 上**：以 Artifact 開啟時，直接使用你自己的 Claude 帳號，不需要 API 金鑰。第一次送出時會詢問是否允許。
- **在其他地方**（GitHub Pages、本機檔案）：按「設定」貼上 Anthropic API 金鑰。金鑰只存在這個瀏覽器，直接傳送到 `api.anthropic.com`，使用 Claude Opus 5.5。

草稿、選項與最近 30 筆紀錄都只存在瀏覽器的 localStorage。

整個工具就是 `index.html` 一個檔案，不需要建置。快捷鍵：`⌘/Ctrl + Enter` 送出，`Esc` 停止。
